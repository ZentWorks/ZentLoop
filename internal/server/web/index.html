ZENTLOOP SETTINGS

Trusted Domains

One root domain per line. A root automatically trusts all of its subdomains. Untrusted historical hosts disappear from fake-target statistics immediately after they become trusted.

Enter one root domain per line. Subdomains are trusted automatically.
ZENTLOOP HELP

Quick guide

Trusted Domains

Domains that belong to your own infrastructure. Adding a root domain also covers its subdomains. Trusted domains appear as normal targets and are included in the regular target statistics.

Date & Target filters

LIVE is the rolling last 24 hours and keeps receiving new Web and SSH events. Selecting a day or All dates switches to a historical view: live streams are paused and lazy loading stays inside the selected time window. The Target filter can be combined with any time view and groups trusted subdomains under their configured root domain.

Live View

The LIVE button opens a compact realtime page with active Web sessions first, active SSH sessions second and the SSH activity feed below. Selecting a Web session opens its current visit only; earlier visits remain available in IP Intelligence, while JSON export stays session-wide. The view uses the same bounded Admin WebSocket as the dashboard, keeps disconnected/quiet sessions visible for up to 60 seconds as LEFT Ns, and updates countdown text without rebuilding the row under your pointer. The SSH feed automatically uses three, two or one columns depending on screen width.

Untrusted hosts

Hosts shown in parentheses were requested by a visitor but are not trusted as one of your own domains. They are evaluated separately so they do not distort your normal target statistics. If you trust one later, its retained history is reclassified automatically.

Host sweeps

ZentLoop can recognize when one visitor rapidly tries many different host names. These attempts stay in the untrusted-host view and may be guided into a generic Web Trap instead of being treated as real targets.

Integration / Proxy

When ZentLoop is used behind a compatible proxy or upstream integration, the original public target and visitor information can be preserved. Proxy integrations can preserve the original target, while trusted domains remain explicitly controlled here by the administrator.

Web Sessions

Shows activity against the Web Traps, including the requested paths and how far a visitor follows the presented breadcrumbs.

SSH Sessions

Shows SSH login attempts, commands and movement through the virtual SSH environment and its deception paths.

Self Protection

These counters show when ZentLoop protects itself instead of serving unlimited work, for example by shedding excess live viewers, limiting SSH abuse or warning when retained storage grows unusually high.

Payload & Canary Intelligence

This is passive observation only. ZentLoop extracts sanitized remote URLs, hosts, filenames and decoy-token reuse from traffic it already received; it does not fetch or execute the indicator. Repeated observations are grouped in the dashboard by indicator while the underlying raw intelligence events remain retained.

IP Intelligence

Click an observed source IP to open a dedicated cross-protocol view with Web/SSH history, authentication cadence, usernames, clients, commands, paths, payload/canary signals and heuristic campaign correlations. The JSON export contains the retained source profile, sessions, events and passive intelligence in one document. Campaign confidence is correlation evidence only and is never an identity claim.

RiskHow suspicious or aggressive the observed session currently appears.
